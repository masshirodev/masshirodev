# Hi there, I'm masshirodev 👋

I'm a developer passionate about building tools that streamline workflows and automate the mundane. I spend a lot of time in the intersection of **game scripting** and **custom development environments**.

### 🛠 What I'm building
- **[ranma](https://github.com/masshirodev/ranma)**: A tiling window manager for the terminal — i3's tree, Hyprland's dwindle, configured in Lua. Written in Rust.
- **[ai-session](https://github.com/masshirodev/ai-session)**: A Go CLI that keeps AI coding tools (Claude Code, Codex, OpenCode) in isolated per-profile sessions, and lets the agents find and message each other.
- **[minion-quick-start](https://github.com/masshirodev/minion-quick-start)**: A public template for rapid development of MMOMinion addons in Lua.
- **[ZenForge](https://github.com/masshirodev/zenforge)**: Developing a dedicated IDE for the GPC language.
- **[TooManyFish](https://github.com/masshirodev/TooManyFish)**: A utility addon for inventory management and fishing automation in FFXIV.

### 🎮 Melvor Idle mods
- **[melvor-auto-sailing](https://github.com/masshirodev/melvor-auto-sailing)**: Automates the Sailing skill's trade loop, so ships never sit idle waiting for a click.
- **[melvor-auto-enchanting](https://github.com/masshirodev/melvor-auto-enchanting)**: Bulk disenchanting, enchant-until-grade and reroll-until-modifier for the Enchanting mod.
- **[melvor-requirement-remover](https://github.com/masshirodev/melvor-requirement-remover)**: Removes equip requirements from every item, Into the Abyss gear included.
- **[melvor-requirement-filler](https://github.com/masshirodev/melvor-requirement-filler)**: Cost-filler buttons wherever you can't afford something, plus an Item Adder page.

### ⌨️ Development Environment
- **Neovim Enthusiast:** I maintain a few plugins:
  - **[remote-mirror.nvim](https://github.com/masshirodev/remote-mirror.nvim)**: Work on projects on SSH hosts as named Neovim workspaces, while Neovim, language servers and formatters stay local.
  - **[osaka-jade-nvim](https://github.com/masshirodev/osaka-jade-nvim)**: A deep green, low-glare colorscheme with jade syntax accents.
  - **[rayso-snap.nvim](https://github.com/masshirodev/rayso-snap.nvim)**: Quickly turn code snippets into beautiful images via ray.so.
- **VS Code:** Contributing to and maintaining GPC language support via **[gpc-vscode](https://github.com/masshirodev/gpc-vscode)**.
