# Hi there, I'm masshirodev 👋

I'm a developer passionate about building tools that streamline workflows and automate the mundane. I spend a lot of time in the intersection of **game scripting** and **custom development environments**.

### 🛠 What I'm building
- **[minion-quick-start](https://github.com/masshirodev/minion-quick-start)**: A public template for rapid development of MMOMinion addons in Lua.
- **[gpc-ide](https://github.com/masshirodev/gpc-ide)**: Developing a dedicated IDE for the GPC language.
- **[TooManyFish](https://github.com/masshirodev/TooManyFish)**: A utility addon for inventory management and fishing automation in FFXIV.
- **[dotfiles](https://github.com/masshirodev/dotfiles)**: My personal Hyprland configuration and desktop environment setup.

### ⌨️ Development Environment
- **Neovim Enthusiast:** I maintain **[rayso-snap.nvim](https://github.com/masshirodev/rayso-snap.nvim)**, a tool to quickly turn code snippets into beautiful images via ray.so.
- **VS Code:** Contributing to and maintaining GPC language support via **[gpc-vscode](https://github.com/masshirodev/gpc-vscode)**.
